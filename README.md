# Applied Data Analysis

Набор Jupyter Notebook по прикладному анализу данных.

## Структура

- `HW1_gan.ipynb` — GAN и генеративные модели;
- `HW2_sound_deep_learning.ipynb` — deep learning для звуковых данных;
- `HW3_time_series_prediction.ipynb` — прогнозирование временных рядов;
- `HW4_recomending_systems.ipynb` — рекомендательные системы.

Проекты показывают применение Python и ML к разным типам данных и задачам.
